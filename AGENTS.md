# AGENTS.md

Este archivo define instrucciones locales para asistentes automatizados que trabajan en este repositorio.

## Objetivo del proyecto
- Plataforma Fellowship: sistema para gestionar equipos, tareas, entregas, aprobaciones y reservas en programas estudiantiles.

## Estilo de trabajo
- Responder y documentar en español neutral.
- Evitar lenguaje excesivamente técnico en documentos dirigidos a usuarios finales.
- Mantener cambios claros, pequeños y trazables.

## Edición de documentos
- Usar LaTeX para informes (`informe.tex`) y mantener lenguaje simple cuando se pida.
- Usar UTF-8 y evitar caracteres especiales innecesarios.

## Flujo sugerido
- Antes de editar, revisar si existe un archivo base para reutilizar.
- Preferir cambios mínimos cuando el usuario pida ajustes de contenido.

## Convenciones
- Rutas relevantes:
  - `informe.tex`: informe general del proyecto.
  - `api/`, `web/`: código principal del backend y frontend.

## Notas
- Si se requiere información del funcionamiento interno, leer primero documentación existente en el repositorio.
